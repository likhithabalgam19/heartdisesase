
# ❤️ Heart Disease Prediction System

## 📌 Project Overview

The **Heart Disease Prediction System** is an end-to-end Machine Learning project developed to predict the likelihood of heart disease using patient health parameters. The project follows the complete Machine Learning lifecycle, including data collection, preprocessing, exploratory data analysis (EDA), feature engineering, model training, evaluation, model serialization, and deployment.

A trained Machine Learning model is integrated with a **Flask REST API** and an interactive **Streamlit** web application to provide real-time heart disease risk predictions through a user-friendly interface. This project demonstrates the practical application of Machine Learning in healthcare by supporting early risk prediction and data-driven decision-making.

---

## 🎯 Problem Statement

Heart disease is one of the leading causes of death worldwide, making early detection essential for improving patient outcomes. Traditional diagnosis often requires multiple medical tests and expert evaluation, which can be time-consuming.

The objective of this project is to develop a Machine Learning-based prediction system that analyzes patient health parameters and estimates the likelihood of heart disease. The system aims to assist healthcare professionals by providing quick, accurate, and reliable predictions, enabling timely medical intervention and better clinical decision-making.
