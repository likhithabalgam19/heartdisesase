# ❤️ Heart Disease Prediction System

## 📌 Project Overview

The **Heart Disease Prediction System** is a Machine Learning project developed by **Likhitha Balgam** to predict the possibility of heart disease using patient health parameters.

The project includes the complete Machine Learning workflow, including data preprocessing, feature engineering, model training, evaluation, and deployment. The trained model is integrated with a **Flask API** for backend prediction and a **Streamlit application** to provide an interactive user interface for real-time predictions.

This project demonstrates the practical use of Machine Learning in healthcare by helping identify heart disease risks and supporting data-driven decision-making.

**GitHub Repository:**
https://github.com/likhithabalgam19/heartdisesase

## 🎯 Problem Statement

Heart disease is one of the leading causes of death worldwide. Early detection of heart disease risk can help in providing timely medical support and improving patient outcomes.

The objective of this project is to build a Machine Learning-based prediction system developed by **Likhitha Balgam** that analyzes patient health information and predicts the likelihood of heart disease. The system provides a simple and efficient way to assess heart disease risk using Machine Learning techniques.
